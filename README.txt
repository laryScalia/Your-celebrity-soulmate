# ❤️ Site de 1 ano de namoro

## Como abrir

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito nele e use "Open with Live Server".

## Onde colocar as fotos

Coloque suas fotos dentro da pasta:

fotos/

E renomeie para:

foto1.jpg
foto2.jpg
foto3.jpg
foto4.jpg

Você pode usar PNG também, mas nesse caso altere `.jpg` para `.png` no `index.html`.

## Onde trocar o nome

Abra `script.js` e procure:

const SEU_NOME = "SEU NOME";

Troque por seu nome.

## Onde trocar os textos

No `index.html`, procure os textos:

ESCREVA AQUI O SEU TEXTO

e substitua pelas mensagens que quiser.

A declaração final também está no final do `index.html`.

## Como colocar mais fotos

Copie um bloco `<article class="memoria">...</article>` e altere:

- a foto
- o título
- o texto
- o número

O CSS já alterna foto e texto automaticamente quando você usa
`class="memoria invertida"`.

Feito para ser simples de editar no VS Code. ❤️
